# my philosophy

会話や日々の意思決定から見つかった思想を、時間をかけて育てる公開リポジトリです。

## 思想の置き場所

- `principles/`：複数の場面で判断を導く原則。
- `beliefs/`：世界、仕事、技術などをどう捉えているか。
- `frameworks/`：判断や学習に繰り返し使う考え方。
- `essays/`：一つの問いをまとまった文章で考えた記録。
- `decisions/`：選択と、そのときの条件や理由。
- `influences/`：考え方へ影響した本、人、言葉。
- `knowledge/daily/`：会話から抽出した日次の根拠。
- `changelog/`：公開している思想の変化。

日次ノートはそのまま長期的な思想とみなさず、異なる場面で繰り返し確認できた内容だけを各カテゴリへ反映します。

## サイト

MarkdownをAstroで読み込み、GitHub Pagesへ公開します。

```bash
npm install
npm run dev
```
