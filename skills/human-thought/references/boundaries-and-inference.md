# 隣接概念と解釈の注意

日常語では近い言葉が混ざりやすい。

ここでの区別は学問分野すべてに通用する定義ではなく、考え方を丁寧に整理するための使い分けである。

## 隣接概念との違い

- **意見**：特定の論点についての判断や主張。
- **好み**：快、不快、欲求、使いやすさに関わる選好。
- **信念**：何が真実で、現実がどうなっているかについての受け取り。
- **価値観**：何が望ましく、尊重に値するかについての評価。
- **原則**：価値や目的が衝突するときにも判断を導く規則。
- **態度**：対象への評価的な構え。
- **世界観**：世界や人間についての広い理解の枠組み。
- **哲学**：概念や理由を意識的に吟味し、体系化しようとする営み、またはその体系。
- **イデオロギー**：社会や政治のあり方について、集団的な説明、規範、実現の構想を伴う考えの体系。

思想はこれらのどれか一つと同義ではない。

複数の要素が結び付き、繰り返しの判断を方向づけるときに、思想として記述しやすくなる。

## 他者の思想を推測するとき

本人の思想を理解するには、本人の言葉を最も強い根拠として扱う。

その言葉が複数の場面で繰り返され、理由や優先順位まで説明されていれば、より安定した理解につながる。

行動は補助的な根拠にとどめる。

行動には、時間、金銭、権限、役割、周囲からの圧力などが影響するためである。

根拠の強さは、おおむね次の順に扱える。

1. 本人が継続して語る自己理解と、その理由。
2. 異なる場面で一貫して現れる発言や選択。
3. 制約を確認したうえで解釈した行動。
4. 単発の発言、引用、所属、印象。

この順序は真実を保証しない。

解釈を示すときは「この発言は、Xという価値を重視している可能性を示す」のように、観察と推測を分ける。

## 断定を避ける問い

思想の理解を深めるには、ラベルを与える前に理由と例外を尋ねる。

- その判断で、何を守ろうとしているのか。
- 何が事実だと考えているのか。
- 何と何が衝突したとき、どちらを優先するのか。
- その考えは、どの経験や場面で変わったのか。
- 別の状況でも同じように考えるのか。

答えが得られない場合は、思想のラベルではなく、観察できる発言や行動だけを記述する。
